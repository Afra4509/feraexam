FAQ

FREQUENTLY ASKED QUESTIONS

Apa itu FeraExam dan perbedaannya dengan Safe Exam Browser (SEB)? ▼

FeraExam adalah browser ujian modern yang dikembangkan berbasis Safe Exam Browser (SEB). FeraExam dirombak total dengan fokus pada performa super gegas (Chromium berakselerasi GPU), fleksibilitas penuh (screenshot diizinkan dan support seluruh website ujian), identitas visual baru, serta penanganan error otomatis yang ramah pengguna.

Apakah FeraExam mengizinkan screenshot dan capture layar? ▼

Ya! Fitur anti-screenshot (DisplayAffinity Guard) telah dinonaktifkan secara khusus di FeraExam. Pengawas atau sistem proctoring dapat mengambil tangkapan layar tanpa terhalang layar hitam (blackout).

Apakah FeraExam bisa membuka semua website ujian online? ▼

Ya, seluruh konfigurasi filter URL yang kaku telah disesuaikan agar FeraExam dapat memuat Google Forms, Quizizz, Moodle, Kahoot, portal CBT sekolah/kampus, dan LMS berbasis web modern tanpa pesan "Page Blocked".

Bagaimana cara menginstal FeraExam di Windows? ▼

Cukup unduh FeraExam_Setup.exe dari halaman ini atau GitHub Releases, jalankan wizard instalasi, dan ikuti instruksi 1-klik. FeraExam akan langsung tersedia di Desktop dan Start Menu Anda.

Apakah tersedia versi portable tanpa perlu install? ▼

Ya, kami juga menyediakan paket FeraExam_Portable_v3.8.0.zip di GitHub Release. Cukup ekstrak filenya ke folder mana saja dan klik ganda FeraExam.exe.
