// SECTION 03 — SYSTEM ARCHITECTURE & MODIFICATIONS

ENGINEERED OVERHAUL SPECIFICATIONS

Setiap modifikasi di bawah ini telah diimplementasikan langsung di dalam kode sumber runtime FeraExam v3.8.0.

SPEC // 01 [IMPLEMENTED]

CHROMIUM GPU RASTERIZATION & ZERO-COPY PIPELINE

SUBSYSTEM: CefSharp / Chromium Embedded Framework

Safe Exam Browser standar sering mengalami bottleneck rendering pada ujian berbasis canvas atau animasi DOM berat. FeraExam menginjeksi flag kompilasi GPU langsung ke dalam inisialisasi CEF serta mematikan background telemetry dan sinkronisasi otomatis bawaan Chromium.

// RUNTIME CHROMIUM COMMAND-LINE FLAGS PIPELINE
--enable-gpu-rasterization Direct GPU viewport tile rendering
--enable-zero-copy Direct texture memory transfer
TELEMETRY_STRIPPED Zero background network overhead
SPEC // 02 ZERO DISPLAY AFFINITY LOCKS

UNRESTRICTED SCREEN CAPTURE & PROCTORING

Kunci WDA_MONITOR / DisplayAffinity telah dilepas sepenuhnya. Peserta maupun perangkat lunak pengawas (OBS, Zoom, aplikasi proctoring pihak ketiga, dan tombol PrintScreen) dapat mengambil tangkapan layar tanpa menghasilkan layar hitam (blackout).

WIN32_API_HOOK: SetWindowDisplayAffinity → BYPASSED (WDA_NONE)
SPEC // 03 UNIVERSAL WEB SUPPORT

OPEN CBT & LMS FILTER MATRIX

Filter aturan URL yang kaku telah dikalibrasi ulang agar seluruh platform ujian modern—termasuk Google Forms, Quizizz, Moodle, Kahoot, dan portal CBT sekolah/kampus—terbuka tanpa interupsi "Page Blocked".

COMPATIBILITY: HTTP/HTTPS • WebSockets • WebRTC Media
SPEC // 04 — PROCESS GUARD

SMART SUBPROCESS REDIRECT

Menjalankan sub-proses client secara langsung otomatis dialihkan ke launcher utama FeraExam.exe tanpa melempar fatal exception Invalid arguments.

SPEC // 05 — WPF BITMAP ENGINE

NATIVE 32-BIT DIB ICONS

Seluruh aset ikon dikonversi ke format 32-bit DIB Bitmap native untuk mengeliminasi crash TypeConverterMarkupExtension pada runtime .NET Framework 4.8 di Windows 10 & 11.

SPEC // 06 — PACKAGING

LZMA2 SINGLE-FILE WIZARD

Paket installer mandiri (FeraExam_Setup.exe, 139.9 MB) dengan setup wizard bertema FeraExam, registrasi shortcut Desktop/Start Menu, dan uninstaller bersih.

INSTALLATION & RUNTIME DOCUMENTATION

01. SYSTEM REQUIREMENTS
  • OS: Windows 10 / 11 (64-bit)
  • RUNTIME: .NET Framework 4.8 (Built-in)
  • VISUAL C++: VC++ 2015–2022 Redist x64
  • DISK SPACE: ~450 MB Extracted
02. UNINSTALLATION PROCEDURE

Untuk menghapus instalasi FeraExam secara menyeluruh tanpa meninggalkan residu konfigurasi:

  1. Buka Windows Settings → Apps → Installed Apps.
  2. Cari entri FeraExam v3.8.0 dan pilih Uninstall.
  3. Atau jalankan unins000.exe langsung dari direktori instalasi FeraExam.
03. STANDARD INSTALLATION & FIRST-LAUNCH WORKFLOW
STEP_01

Acquire Binary

Unduh FeraExam_Setup.exe (139.9 MB) melalui Release Console di atas atau pilih arsip Portable .zip (199.5 MB) jika tidak memiliki akses Administrator.

STEP_02

Execute Setup Wizard

Jalankan installer, pilih lokasi direktori, dan aktifkan opsi pembuatan shortcut Desktop. Untuk versi Portable, ekstrak seluruh isi ZIP ke satu folder utuh.

STEP_03

First-Launch & Exam

Buka aplikasi melalui launcher utama FeraExam.exe atau klik ganda file konfigurasi .seb dari penyelenggara ujian.

04. TROUBLESHOOTING & OS SECURITY COMPLIANCE [KEEP DEFENDER ENABLED]

jangan matikan antivirus atau keamanan sistem operasi: Anda tidak perlu menonaktifkan Windows Defender atau kontrol keamanan Windows untuk menjalankan FeraExam. Jika muncul dialog Windows SmartScreen (karena sertifikat code-signing komunitas), verifikasi bahwa nama file adalah FeraExam_Setup.exe dari repositori resmi Afra4509/feraexam dan cocokkan nilai checksum SHA-256 sebelum melanjutkan.
